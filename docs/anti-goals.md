# Anti-Goals

Do not build these unless a future mission explicitly changes the product scope.

## Product Anti-Goals

- Generic testimonial sections.
- Blog/CMS work before the interactive proof path is excellent.
- Team, billing, pricing, or account settings for public visitors.
- Analytics dashboards that are not used to improve visitor experience.
- More hidden features before existing ones are discoverable and documented.

## UX Anti-Goals

- Landing-page filler.
- Oversized marketing copy that delays access to proof.
- Effects that obscure text, controls, or project screenshots.
- Mobile layouts that require horizontal scanning.
- Empty states that say "coming soon" instead of giving a useful next action.

## Engineering Anti-Goals

- Broad rewrites without a current mission.
- New dependencies for one-off UI effects.
- Auth, middleware, or database changes unless acceptance criteria require them.
- Large visual-system churn mixed with feature work.
- Tests skipped without a documented reason.
