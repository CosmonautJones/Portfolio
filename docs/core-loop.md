# Core Loop

## Visitor Loop

```text
Visitor lands on the site
-> sees a clear interactive-proof promise
-> opens a project, demo, game, or tool
-> experiences a working artifact
-> decides Travis can ship
-> contacts or shares the work
```

## Admin Loop

```text
Travis builds or imports a working artifact
-> documents the value and implementation
-> publishes it through the tool/project system
-> the public site gains another proof point
```

## First 60 Seconds

The first minute should answer:

1. Who is this?
2. What does he build?
3. What can I click right now?
4. Why is this more credible than a normal portfolio?
5. How do I contact him if the proof is convincing?

## Magic Moment

The visitor clicks into something that behaves like a real product, not a mock:
a playable game, a useful demo, a polished tool, or a hidden interactive layer.

## Must Feel Excellent Before New Features

- Home page path from claim to proof.
- Featured project framing.
- Contact flow.
- Demo/game loading and failure states.
- Mobile readability and touch targets.
