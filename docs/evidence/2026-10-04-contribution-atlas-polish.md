# Contribution atlas polish

The homepage atlas now uses the portfolio's typography, rules, background, and signal colors. Both the interface and canvas respond to the existing theme picker: midnight, ocean, ember, and emerald in light and dark mode. The canvas palette follows the same five contribution levels as the legend. A native date input and previous/next controls let visitors inspect exact dates without tapping tiny cells on a phone.

Recent public changes appear as three compact links below the calendar. `/api/github-activity` uses only the unauthenticated public GitHub events endpoint and public commit lookups. It validates public visibility and repository/SHA/PR targets, sorts and deduplicates candidates, and limits enrichment to three changes. Its response exports only repository, kind, first-line title, canonical GitHub link, and date. No credential, email, commit body, patch, private repository metadata, dependency, auth change, or database change is involved. Feed failures leave the calendar usable and provide a GitHub link; partial enrichment preserves successful records.

The calendar remains an aggregate contribution calendar, including commits, pull requests, issues, and reviews. It is not attributed to TravOS. Public changes are a recent sample, not a breakdown of the year's totals. GitHub documents anonymized private contributions and delayed/limited public events in its [contribution guide](https://docs.github.com/en/account-and-profile/concepts/contributions-on-your-profile) and [events API reference](https://docs.github.com/en/rest/activity/events).
