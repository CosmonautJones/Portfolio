# Alcubemy: Matter Lab portfolio preview

Alcubemy: Matter Lab remains the first Playground item on `/work`, linking to
`https://alcubemy.travisjohnjones.com/`. The release adds adjustable gravity,
exotic materials, reusable blueprints and full experiment setups to the game.

`public/projects/alcubemy-matter-lab.png` is a 1600 × 900 browser screenshot of
the actual November 4, 2026 Matter Lab build. It shows the Chaos yard with the
blueprint library open. The card uses this capture instead of the older
reaction video, so the preview matches the experience visitors will open.

The catalog has 73 entries: 72 paintable materials and air. Eight built-in
blueprints and five setups include buildings and creature habitats. The card
states that connected structures translate and that physics is playful; it
does not claim engineering-grade structural or thermal accuracy.

The old `alcubemy-reaction.mp4` and `alcubemy.png` assets remain available for
historical links. Component tests still exercise optional video rendering;
project data tests require the current screenshot and the unchanged game URL.
The work-page test keeps the card first in Playground and prevents duplication.
