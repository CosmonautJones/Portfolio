# Alcubemy: V2 Playground portfolio preview

Alcubemy: V2 Playground remains the first Playground item on `/work`, linking
to `https://alcubemy.travisjohnjones.com/`. V2 is the default experience, with
experimental Matter Lab available through the visible mode switch.

`public/projects/alcubemy-v2-playground.png` is a 1600 × 900 browser screenshot
of the actual November 4, 2026 V2 build. It shows the opening vessel, reagent
palette and visible mode switch. The card uses this capture so the preview
matches the experience visitors will open.

V2 offers the alchemical vessel, discoveries, codex and living habitats.
Experimental Matter Lab provides adjustable gravity, 72 paintable materials
plus air, eight blueprints and five setups. Its physics remains playful and
qualitative, not an engineering model.

The old `alcubemy-reaction.mp4`, `alcubemy.png` and `alcubemy-matter-lab.png`
assets remain available for historical links. Component tests still exercise optional video rendering;
project data tests require the current screenshot and the unchanged game URL.
The work-page test keeps the card first in Playground and prevents duplication.
