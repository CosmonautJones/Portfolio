# Vision

## What This Is

This is Travis Jones's interactive portfolio and tool hub. It combines a public
portfolio, playable demos, a real browser game, a progression layer, an admin
tool system, and hidden discovery paths.

## Target User

- A technical hiring manager or collaborator deciding whether Travis can ship.
- A developer peer inspecting implementation quality.
- A curious visitor who is more likely to remember a working artifact than a
  static resume.

## Job To Be Done

This site is for someone evaluating Travis's work who wants fast evidence of
product sense and engineering ability, but keeps seeing generic portfolios that
only claim skill. It helps them inspect, play, and use real examples so the
portfolio demonstrates capability directly.

## Product Wedge

Interactive proof beats static self-description.

The site should make the visitor think: "This person builds things I can
actually touch." The game, demos, terminal, progression system, and tool hub are
not decorations; they are evidence.

## Enemy

- Generic portfolio sections with no working proof.
- Novelty that does not support credibility.
- Hidden features that are impossible to discover.
- Overbuilt admin/tooling paths that do not improve the public experience.
- Visual polish that slows the site or weakens readability.

## Success Criteria

- A first-time visitor understands the interactive-proof wedge within 60 seconds.
- Featured projects expose working demos or concrete implementation detail.
- The contact path is obvious after a visitor sees proof.
- Hidden/advanced features reward exploration without blocking the primary path.
- Agents can pick one scoped improvement without re-litigating the product.
