# Product Rubric

Score each mission from 1 to 5.

## Wedge Clarity

Does the change strengthen the "interactive proof beats static claims" wedge?

1. Could belong to any portfolio.
3. Some proof is clearer, but the path still feels generic.
5. The visitor immediately understands what makes this portfolio specific.

## Visitor Value

Does the visitor get to inspect, play, or use something meaningful faster?

1. Adds content but no useful action.
3. Improves navigation or framing.
5. Creates a faster path to a working artifact and clear next action.

## Scope Discipline

Does the mission avoid generic bloat?

1. Adds unrelated sections/features.
3. Mostly scoped, with some extra polish or copy churn.
5. Only changes what the mission needs.

## Credibility

Does the change make Travis look more capable through evidence?

1. Relies on claims.
3. Mentions concrete work.
5. Lets the work demonstrate quality directly.

## Agent Readiness

Can another agent continue from the docs and current mission without guessing?

1. Mission is vague.
3. Mission has scope but weak acceptance criteria.
5. Mission has files, acceptance criteria, anti-goals, and checks.
